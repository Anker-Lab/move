Tilmeld dig Se Program

Årets tema: LUK OP

MOVE er Kirkeibyens årlige konference, hvor vi samles på tværs af vores lokationer. Det er en weekend med fællesskab, vision og tid sammen som kirke.

Vi mødes for at dele livet i hverdagen, styrke relationer og blive inspireret til det, vi står i som fællesskab.

MOVE handler ikke om én lokation — men om hele Kirkeibyen samlet som én kirke.
